# Sprint_7
1. data содержит два используемых класса (Api и Urls), требуемых для удобной работы.
2. helpers содержит два класса: DataGeneration (для создания курьера) и DataGenerationOrder (для создания заказа).
3. conftest содержит функцию-фикстуру по созданию и последующему удалению аккаунта курьера.
4. scooter_api содержит используемые вызовы к api.
5. Создан allure-отчет (allure-results).
6. Создан файл с внешними зависимостями requirements.txt и файл .gitignore.
7. Сами тесты описаны в директории test: test_create_courier.py, test_create_order.py, test_login_courier.py, test_order_list.py.
7.1. test_create_courier.py проверяет возможность создания курьера(с корректным кодом и статусом), невозможность создания двух одинаковых аккаунтов и невозможности регистрации без одного обязательного поля.
7.2. test_login_courier.py проверяет успешность логина курьера в систему, попытка входа без пароля, проверка логина несуществующим курьером.
7.3. test_create_order.py проверяет корректное создание заказа.
7.4. test_order_list.py проверяет тело ответа на запрос списка заказов.
